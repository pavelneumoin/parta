# Парта · Доска — видение функций по предметам

Заказ Павла (2026-07-07): «похоже на Миро, но мне надо много-много функций
дополнительных для разных предметов». Референс:
class.репетитор-кузьмин.рф/board/demo. Отличие Парты от Миро и от Кузьмина —
**предметные инструменты учителя математики/информатики + банк Неумошки**.

## Архитектура (в мокапе уже работает)

- **Виджет-система**: инструмент = плагин `{id, subject, name, icon, run()}`,
  спавнит draggable-виджет на доске. Добавление нового инструмента = один блок кода.
- **Сундучок** в левом тулбаре → вкладки предметов (Математика · Геометрия ·
  Информатика · Вер/стат · Урок) + переключатель фона (клетка / линейка /
  координатная плоскость / чистый).
- Рисование (перо/маркер/ластик/лазер/штампы) — слой canvas ПОД виджетами.
- **ИИ-композер** сверху: «что добавить на доску» → чипы Задача из банка /
  Схема / Клетка, модель «Неумошка ИИ».

## Инструменты в мокапе v2 (17, все работают)

| Предмет | Инструменты |
|---|---|
| Математика | **График функции** (парсер y=f(x), несколько графиков через `;`) · **Числовая прямая** (точки [закр./(выкол., интервалы со штриховкой) · **Дроби наглядно** (круг n/m + смешанное число) · **Тригокруг** (тянешь точку — угол °/рад, sin/cos с проекциями) |
| Геометрия | **Треугольник ABC** (вершины тянутся, длины сторон live в клетках) · **Окружность** (тянешь радиус — R, C=2πR, S=πR²) · **Транспортир** (поворот ±15°) · **Линейка 10 см** (1 см = клетка) |
| Информатика | **Код Python** (редактируемый, подсветка) · **Системы счисления** (2/8/10/16 live) · **Дерево** (клик по узлу → потомки n+1 и n·2 — задания 19–21, Фано) · **Таблица истинности** (A,B,C; and/or/not/xor/→) |
| Вер/стат | **Кубик и монета** (анимация броска, история) · **Диаграмма** (данные → столбцы) |
| Урок | **Таймер** (5/10/15 мин, жёлтый→красный) · **Случайный ученик** (12 имён 7А, рулетка, без повторов) · **Светофор тишины** (3 режима) |

## Дорожная карта продукта

### v1 (перенос в web/ — Next.js, поверх StudentCanvas)
1. Виджет-система как React-компоненты + позиции в БД (sync через существующий polling).
2. Инструменты из мокапа 1-в-1 (они уже чистый JS/SVG — портирование прямое).
3. ИИ-композер → реальный API: банк vault (5385 задач, см. wiki-vault-sync),
   фильтр по теме/классу/сложности; карточка задачи с ответом «под спойлером».
4. Роли: у ученика — перо/ластик только на своём листе; виджеты учителя видны всем
   (broadcast — механика уже есть в Parta).

### v2 (предметная глубина)
- **Математика**: LaTeX-формулы (KaTeX), шаблоны преобразований, столбиком
  (+/−/×/÷), проценты-схемы, единичная окружность со значениями табличных углов,
  GeoGebra-embed для стереометрии (у нас есть ggb_render-опыт).
- **Геометрия**: циркуль (дуги!), угол с дугой и подписью, полный набор фигур
  с вершинами-метками, 3D-каркасы (куб/пирамида, вращение).
- **Информатика**: запуск Python в песочнице (Pyodide), пошаговый трассировщик,
  логические схемы (И/ИЛИ/НЕ с проводами), конвертер + арифметика в СС,
  граф-редактор (матрица смежности ↔ рисунок — задание 1).
- **Вер/стат**: дерево вероятностей с автоперемножением, гистограмма/боксплот,
  серия бросков со статистикой (частота → вероятность).
- **Урок**: голосование A/B/C/D с live-диаграммой (ученики отвечают со своих
  устройств!), «поднять руку», экспорт страницы в PDF-конспект ученикам,
  вставка страницы из library (готовые уроки).

### v3 (интеграции экосистемы)
- Банк: сохранение задачи с доски В банк (обратный поток, стандарт vault).
- WorksheetAI: «сгенерировать лист по этой доске».
- mainEGE: кнопка «в игру» — задача с доски становится уровнем.
- Запись урока: таймлайн штрихов → воспроизведение (как видеоурок).

## Технические заметки

- Мокап: `design/board/board-screen.html` — самодостаточный, без внешних
  зависимостей (CSP-friendly), палитра из `web/tailwind.config.ts`.
- Гоча: вечный rAF-цикл лазера душил скриншотер превью — цикл теперь живёт
  только при активном лазере. В проде тот же принцип: нет активности — нет кадров.
