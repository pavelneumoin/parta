## Решения, принятые ночью без подтверждения

| Решение | Почему |
|---|---|
| SQLite вместо Postgres для dev | Чтобы не блокироваться установкой Postgres локально. Schema совместима, переключение через 1 строку. |
| Polling 2.5 сек вместо WebSocket | Проще, надёжнее, видимый wow-эффект уже есть. WebSocket — после первых живых уроков, если упрёмся. |
| Стирание штриха целиком (не сегмента) | Это что было в прототипе. UX «удалить нарисованную линию» интуитивен. |
| Стирание НЕ синкается на сервер (пока) | В MVP — soft delete на клиенте. Сервер хранит append-only, при рестарте стёртое вернётся. Это будет видно — учитель скажет, доработаю с soft delete API. |
| Учитель видит ученический холст через тот же `/s/[wsid]` | Срезали отдельный teacher-view. Учитель может писать поверх (его штрихи попадают как layer=teacher). Раздельная страница — V2. |
| Длинные имена кнопок и текстов на русском | Без англицизмов; пользователю-учителю так привычнее. |
| Без эмодзи | Стиль школы, не TikTok. |
| join-код только цифрами 2-9 | Чтобы диктовать вслух без путаницы 0/O и 1/I. |
